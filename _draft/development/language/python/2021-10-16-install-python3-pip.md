# 한번 알아보자

## 1. get-pip.py를 다운로드 할 경로로 이동

```bash
$ cd desktop
```

## 2. get-pip.py 다운로드

```bash
$ curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py
```

## 3. Python script 수행을 통한 PIP 설치

```bash
$ python3 get-pip.py
```
