Windows 11에서 Ollama로 Qwen3:8B 실행하기

Windows 11에 Ollama를 설치하고 Qwen3:8B 모델을 로컬에서 실행하는 전체 과정을 정리한다.

📋 이런 내용을 다뤘어요
→ Ollama 하나면 Windows에서도 로컬 LLM을 바로 실행할 수 있다
→ Qwen3:8B는 RTX 4070 12GB에서 VRAM 6GB만 사용하며 돌아간다
→ 설치부터 GPU 활용 확인까지 10분이면 끝난다
→ API 서버가 자동으로 뜨니까 다른 앱과 연동도 바로 가능하다
