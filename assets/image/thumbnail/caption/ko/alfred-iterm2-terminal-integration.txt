Alfred에서 iTerm2를 기본 터미널로 설정하기

Alfred에서 터미널 커맨드를 실행할 때 기본 Terminal.app 대신 iTerm2를 사용하도록 설정하는 방법을 정리한다.

📋 이런 내용을 다뤘어요
→ Alfred 터미널 설정 열기
→ Application을 Custom으로 변경
→ AppleScript 입력
→ Alfred에서 > 접두사를 붙여 커맨드를 입력하면 iTerm2에서 실행되는지…
