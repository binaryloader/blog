심볼릭 링크로 설정 파일을 Git 저장소와 동기화하기

심볼릭 링크를 활용해 특정 경로의 설정 파일을 Git 저장소에서 버전 관리하는 방법을 정리한다.

📋 이런 내용을 다뤘어요
→ 설정 파일을 Git으로 관리하고 싶은데 위치가 제각각일 때
→ 심볼릭 링크 하나로 원본 위치와 Git 저장소를 동기화할 수 있다
→ dotfiles 관리의 기본이 되는 패턴이다
