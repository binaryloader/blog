Claude를 활용한 PR 자동 코드 리뷰 구축기

사이드 프로젝트에서 Claude Code Action으로 GitHub PR 자동 리뷰를 구축한 경험을 정리한다.

📋 이런 내용을 다뤘어요
→ 동생과 사이드 프로젝트를 하는데 서로 코드 리뷰할 시간이 없었다
→ PR을 올리면 Claude가 자동으로 이슈 링크 추가와 코드 리뷰를 해준다
→ 유료 구독자는 API 키 대신 OAuth 토큰으로 무료로 사용할 수 있다
→ 미처 생각하지 못한 엣지 케이스를 찾아주는 게 가장 유용했다
