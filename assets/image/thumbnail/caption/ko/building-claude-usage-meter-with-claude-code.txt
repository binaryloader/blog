Claude Code로 Claude Code 모니터링 앱 만들기

Claude Code를 사용해 자기 자신의 사용량을 모니터링하는 macOS 메뉴바 앱을 만든 경험을 공유한다.

📋 이런 내용을 다뤘어요
→ Claude Code가 자기 자신의 사용량을 모니터링하는 앱을 만들었다
→ 메뉴바에서 실시간 토큰 사용량과 남은 용량을 확인할 수 있다
→ stats-cache.json 파일 하나에 모든 사용량 데이터가 들어있다
→ Claude Code로 Claude Code 앱을 만드는 메타적인 경험이었다
