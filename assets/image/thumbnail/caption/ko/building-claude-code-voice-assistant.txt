야심한 새벽에 만드는 Claude Code 음성 어시스턴트

잠이 안 오는 야심한 새벽에 Claude Code CLI의 입출력을 음성으로 중계하는 macOS 어시스턴트 데모를 만든 경험을 공유한다.

📋 이런 내용을 다뤘어요
→ 잠이 안 와서 새벽에 만든 음성 어시스턴트가 생각보다 잘 동작했다
→ whisper.cpp로 로컬 음성 인식, Google Cloud TTS로 음성 출력을 구현했다
→ 상태 머신으로 녹음 → 인식 → 처리 → 응답 흐름을 제어한다
→ 어시스턴트에 아바타를 넣은 건 완전히 재미 목적이다
