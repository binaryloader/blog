플러그인 없이 Jekyll 블로그 다국어(한/영/일) 구현하기

Jekyll과 Minimal Mistakes 테마에서 플러그인 없이 한국어, 영어, 일본어 3개 국어를 지원하는 블로그를 구현한 경험을 공유한다.

📋 이런 내용을 다뤘어요
→ 플러그인 없이 Jekyll에서 3개 국어 블로그를 구현했다
→ GitHub Pages 호환을 위해 플러그인을 쓸 수 없는 제약이 있었다
→ Liquid 템플릿만으로 언어 감지, 전환, 번역 매칭까지 구현한다
→ 실제로 겪은 Liquid 변수 스코프 오염 문제와 해결법도 공유한다
