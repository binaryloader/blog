Claudeを活用したPR自動コードレビュー構築記

サイドプロジェクトでClaude Code ActionによりGitHub PR自動レビューを構築した経験をまとめる。

📋 こんな内容です
→ 弟とサイドプロジェクトをしているが、お互いコードレビューの時間がなかった
→ PRを上げるとClaudeが自動でイシューリンクとコードレビューをしてくれる
→ 有料プランならAPIキーの代わりにOAuthトークンで無料で使える
→ 思いつかなかったエッジケースを見つけてくれるのが一番便利だった
