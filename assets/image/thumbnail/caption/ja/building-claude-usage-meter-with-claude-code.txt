Claude CodeでClaude Codeモニタリングアプリを作る

Claude Codeを使って自身の使用量をモニタリングするmacOSメニューバーアプリを作った経験を共有する。

📋 こんな内容です
→ Claude Codeが自分自身の使用量をモニタリングするアプリを作った
→ メニューバーからリアルタイムのトークン使用量と残量を確認できる
→ stats-cache.jsonファイル1つに全ての使用量データが入っている
→ Claude CodeでClaude Codeアプリを作るメタ的な体験だった
