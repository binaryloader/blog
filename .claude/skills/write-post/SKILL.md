# /write-post <주제>

주어진 주제로 블로그 포스트를 작성하는 전체 플로우를 실행한다.

## 1. 실행 순서

### 1단계: 포스트 작성

blog-writer 에이전트를 호출하여 한국어, 영어, 일본어 3개 언어 포스트를 작성한다.

- 주제를 분석하고 카테고리/태그를 결정한다
- ref 슬러그를 생성한다
- 한국어 포스트를 먼저 작성한다
- 영어, 일본어 포스트를 작성한다
- 새 카테고리가 필요하면 카테고리 페이지와 navigation.yml도 업데이트한다

### 2단계: 번역 검수

blog-translator 에이전트를 호출하여 영어/일본어 번역 품질을 검수한다.

- 기술 용어 일관성을 확인한다
- 자연스러운 번역인지 검토한다
- 필요 시 수정한다

### 3단계: 썸네일 생성

blog-thumbnail 에이전트를 호출하여 썸네일을 생성한다.

- `illustrations.js`에 커스텀 일러스트 함수를 추가한다
- `generate.js`로 3개 언어 썸네일을 생성한다
- 포스트 Front Matter의 header 블록이 올바른지 확인한다

## 2. 완료 조건

- 3개 언어 포스트 파일이 생성되었다
- Front Matter가 모든 규칙을 준수한다
- 썸네일이 생성되고 경로가 올바르다
- 새 카테고리가 있다면 관련 파일이 모두 업데이트되었다
