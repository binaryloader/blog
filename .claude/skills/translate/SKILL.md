# /translate <파일경로>

기존 한국어 포스트를 영어와 일본어로 번역한다.

## 1. 실행 순서

### 1단계: 원본 확인

한국어 원본 포스트를 읽고 분석한다.

- 파일 경로가 `_posts/ko/`인지 확인한다
- `ref` 필드를 확인한다
- 기존 영어/일본어 버전이 있는지 확인한다

### 2단계: 번역

blog-translator 에이전트를 호출하여 번역한다.

- 영어 버전이 없으면 새로 생성한다
- 일본어 버전이 없으면 새로 생성한다
- 이미 존재하는 버전은 원본과 비교하여 갱신이 필요한 경우에만 수정한다

### 3단계: 검증

번역된 포스트가 규칙을 준수하는지 확인한다.

- Front Matter 필드가 올바른지 확인한다 (lang, permalink 등)
- ref가 원본과 동일한지 확인한다
- 섹션 제목이 언어별 매핑을 따르는지 확인한다

## 2. 완료 조건

- 3개 언어 포스트 파일이 모두 존재한다
- 번역 품질이 자연스럽다
- Front Matter가 모든 규칙을 준수한다
