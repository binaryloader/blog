# Overview

Deploy a React SPA to an S3 bucket and securely serve it with CloudFront OAC, covering caching strategies and lifecycle policies.

# Summary

## 1. S3 Bucket Purposes

S3 is used for 4 purposes in the project.

| Bucket | Purpose | Versioning |
|---|---|---|
| `my-project-{env}-frontend` | React SPA build artifacts | Enabled |
| `my-project-terraform-state` | Terraform state files (S3 native locking) | Enabled |
| `my-project-{env}-documents` | Raw data collected from external APIs | Enabled |
| `my-project-{env}-milvus` | Milvus vector DB object storage | Disabled |

Bucket naming follows the `{project}-{environment}-{purpose}` pattern.

## 2. CloudFront + S3 Static Hosting

### 2.1. OAC (Origin Access Control)

The S3 bucket is fully blocked with Block All Public Access, and access is only allowed through CloudFront OAC. OAC is the latest method replacing the legacy OAI (Origin Access Identity) and uses SigV4 signing.

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowCloudFrontOAC",
      "Effect": "Allow",
      "Principal": {
        "Service": "cloudfront.amazonaws.com"
      },
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-project-prod-frontend/*",
      "Condition": {
        "StringEquals": {
          "AWS:SourceArn": "arn:aws:cloudfront::123456789012:distribution/EDFDVBD6EXAMPLE"
        }
      }
    }
  ]
}
```

### 2.2. SPA Routing

For React Router client-side routing, CloudFront redirects 403/404 responses to `index.html`. When a request comes to a path that does not exist in S3, a 403 (Access Denied) is returned, which must be sent to `index.html` so React Router can handle it.

```hcl
custom_error_response {
  error_code         = 403
  response_code      = 200
  response_page_path = "/index.html"
}

custom_error_response {
  error_code         = 404
  response_code      = 200
  response_page_path = "/index.html"
}
```

### 2.3. Custom Domain + ACM

ACM certificates must be issued in the `us-east-1` region to be attached to CloudFront. Route53 connects the CloudFront distribution as an Alias record.

```hcl
resource "aws_acm_certificate" "frontend" {
  provider          = aws.us_east_1
  domain_name       = "app.example.com"
  validation_method = "DNS"
}
```

## 3. Caching Strategy

| File Type | Cache-Control | TTL | Reason |
|---|---|---|---|
| `index.html` | `no-cache` or `max-age=300` | 5 min | Must reflect deployments immediately |
| JS/CSS (with hash) | `max-age=31536000, immutable` | 1 year | Filename includes content hash |
| Images, fonts | `max-age=86400` | 1 day | Low change frequency |

Content hashes generated by Vite (or Webpack) during build (e.g., `main.a1b2c3d4.js`) uniquely identify files, so hashed files can be safely cached for 1 year. During deployment, only `index.html` needs to be invalidated.

```bash
aws cloudfront create-invalidation \
  --distribution-id E1234567890ABC \
  --paths "/index.html"
```

For users in Korea, `PriceClass_200` is selected as the Price Class. It provides wider Asia coverage than `PriceClass_100` (US/Europe only) and is cheaper than `PriceClass_All`.

## 4. Lifecycle Policies

### 4.1. Data Bucket

Apply lifecycle policies to the data bucket to reduce costs.

- Transition from Standard to Standard-IA after 90 days (~40% savings)
- Transition from Standard-IA to Glacier Instant Retrieval after 1 year
- Consider S3 Intelligent-Tiering if access frequency is hard to predict

### 4.2. Terraform State Bucket

Automatically clean up non-current versions after 90 days to prevent version history from growing indefinitely.

### 4.3. Frontend Bucket

Delete non-current versions from previous deployments after 30 days. A shorter cycle is applied since only the latest build needs to be retained.

## 5. Versioning and Backup

Versioning is enabled on the frontend bucket and Terraform state bucket to allow recovery of accidentally deleted files. The data bucket can use Cross-Region Replication (CRR) for disaster recovery.

## 6. Milvus Storage

Replace MinIO with S3 as Milvus object storage. Using IRSA (IAM Roles for Service Accounts) allows access to S3 without access keys, enhancing security.

```yaml
milvus:
  storage:
    type: S3
    endpoint: s3.ap-northeast-2.amazonaws.com
    bucketName: my-project-prod-milvus
    useIAM: true
```

## 7. Terraform Configuration

The entire S3 + CloudFront setup is managed with Terraform.

```hcl
resource "aws_s3_bucket" "frontend" {
  bucket = "my-project-${var.environment}-frontend"
}

resource "aws_s3_bucket_public_access_block" "frontend" {
  bucket = aws_s3_bucket.frontend.id

  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}

resource "aws_cloudfront_origin_access_control" "frontend" {
  name                              = "frontend-oac"
  origin_access_control_origin_type = "s3"
  signing_behavior                  = "always"
  signing_protocol                  = "sigv4"
}

resource "aws_cloudfront_distribution" "frontend" {
  enabled             = true
  default_root_object = "index.html"
  aliases             = ["app.example.com"]
  price_class         = "PriceClass_200"

  origin {
    domain_name              = aws_s3_bucket.frontend.bucket_regional_domain_name
    origin_id                = "s3-frontend"
    origin_access_control_id = aws_cloudfront_origin_access_control.frontend.id
  }

  default_cache_behavior {
    allowed_methods  = ["GET", "HEAD"]
    cached_methods   = ["GET", "HEAD"]
    target_origin_id = "s3-frontend"

    cache_policy_id = "658327ea-f89d-4fab-a63d-7e88639e58f6"

    viewer_protocol_policy = "redirect-to-https"
    compress               = true
  }

  ordered_cache_behavior {
    path_pattern     = "/assets/*"
    allowed_methods  = ["GET", "HEAD"]
    cached_methods   = ["GET", "HEAD"]
    target_origin_id = "s3-frontend"

    cache_policy_id = "658327ea-f89d-4fab-a63d-7e88639e58f6"

    viewer_protocol_policy = "redirect-to-https"
    compress               = true
  }

  custom_error_response {
    error_code         = 403
    response_code      = 200
    response_page_path = "/index.html"
  }

  custom_error_response {
    error_code         = 404
    response_code      = 200
    response_page_path = "/index.html"
  }

  viewer_certificate {
    acm_certificate_arn      = aws_acm_certificate.frontend.arn
    ssl_support_method       = "sni-only"
    minimum_protocol_version = "TLSv1.2_2021"
  }

  restrictions {
    geo_restriction {
      restriction_type = "none"
    }
  }
}
```

## 8. Cost

| Item | Monthly Cost |
|---|---|
| S3 Storage (5GB) | ~$0.12 |
| S3 Requests | ~$1 |
| CloudFront (50GB transfer) | ~$5 |
| Estimated total | ~$6/month |

Costs can be minimized by properly configuring S3 lifecycle policies and CloudFront caching.
