# Overview

This post covers how to install and use the Alfred TimeZones Workflow on macOS.

# Steps

## 1. Check Timezones

```
> tz
```

## 2. Add a City

```
> timezone add {city name}
```

## 3. Edit

```
> timezone edit
```
