## 1. Overview

Caffeine is a macOS menu bar app that prevents system sleep so your Mac stays awake.

## 2. Info

- Developer: Claude Code
- Designer: Claude Design
- Version: 1.0.0
- License: MIT
- Requirements: macOS 14.0+
- GitHub: [binaryloader/caffeine](https://github.com/binaryloader/caffeine)

## 3. Features

- Quick timer presets (5min, 15min, 30min, 1h, 2h, 5h) plus a custom timer
- Five sleep prevention options (display, idle, disk, AC power, user activity)
- Auto-launch at login
- Localized in Korean, English, and Japanese
- Glass morphism dark UI
