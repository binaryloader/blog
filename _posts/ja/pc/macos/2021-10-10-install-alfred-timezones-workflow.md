# 概要

macOS で Alfred TimeZones Workflow をインストールして使用する方法をまとめる。

# 手順

## 1. タイムゾーンの確認

```
> tz
```

## 2. 都市の追加

```
> timezone add {city name}
```

## 3. 編集

```
> timezone edit
```
