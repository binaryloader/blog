# 개요

macOS에서 Alfred TimeZones Workflow를 설치하고 사용하는 방법을 정리한다.

# 정리

## 1. Timezones 확인

```
> tz
```

## 2. 도시 추가

```
> timezone add {city name}
```

## 3. 편집

```
> timezone edit
```
