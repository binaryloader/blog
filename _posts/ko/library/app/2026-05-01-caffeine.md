## 1. 개요

Caffeine은 macOS 시스템 sleep을 차단해 Mac이 잠들지 않게 유지하는 메뉴바 앱이다.

## 2. 정보

- 개발: Claude Code
- 디자인: Claude Design
- 버전: 1.0.1
- 라이선스: MIT
- 요구사항: macOS 14.0+
- GitHub: [binaryloader/caffeine](https://github.com/binaryloader/caffeine)

## 3. 주요 기능

- 빠른 타이머 프리셋(5분, 15분, 30분, 1시간, 2시간, 5시간) 및 사용자 지정 타이머
- 5종 잠자기 방지 옵션(디스플레이/유휴/디스크/AC 전원/사용자 활성)
- 로그인 시 자동 시작
- 한국어/영어/일본어 다국어
- 글래스 모피즘 다크 UI
