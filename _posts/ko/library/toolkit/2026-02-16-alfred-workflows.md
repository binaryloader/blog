## 1. 개요

alfred-workflows는 macOS Alfred 런처용 커스텀 워크플로 모음이다.

## 2. 정보

- 개발: binaryloader
- 라이선스: MIT
- 요구사항: Alfred 4+
- GitHub: [binaryloader/alfred-workflows](https://github.com/binaryloader/alfred-workflows)

## 3. 포함된 워크플로

- [Jekyll Time Format](https://github.com/binaryloader/alfred-workflows/tree/main/jekyll-time-format) - 키워드 `jt`로 호출하면 현재 시각을 `YYYY-MM-DDTHH:MM+09:00` 형식의 KST 타임스탬프로 클립보드에 복사한다. Jekyll 포스트 frontmatter의 `last_modified_at` 갱신에 사용한다

## 4. 설치

각 워크플로 폴더 안의 `.alfredworkflow` 파일을 더블 클릭하면 Alfred에 자동 import된다.
